# Eiki

## About

Eiki is an English education app. It's purpose is:

1. To provide users with graduated reading passages and reading comprehension questions across the range of CEFR levels (A1 to C2).
2. To allow users to save challenging vocabulary words and review them using spaced repetiton.
3. To provide a fully bi-lingual experience (English and Japanese).

## Roadmap

- [x] Provide users with readings passages for A1 and A2.
- [x] Allow users to check their learning status in their dashboard.
- [ ] Allow users to save words for later review.
- [ ] Provide users with reading passages for B1 and B2.
- [ ] Provide users with reading passages C1 and C2.

## Tech Stack

- Main application language: TypeScript
- Framework: Next.js (app router)
- Database: PostgreSQL
- ORM: Drizzle
- Internationalization: next-intl
- Validation: Zod
- CSS styling: Tailwind CSS with shadcn/ui
